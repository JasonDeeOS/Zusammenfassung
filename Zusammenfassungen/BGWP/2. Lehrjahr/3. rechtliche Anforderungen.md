- Gefährdung durch Risiken
- Forderung nach Governance und damit einem Regelsystem zur Vermeidung von Risiken
- Regeltreue = Compliance

## Beispiele für steigende Risiken

- Umsetzung gesetzlicher Anforderungen -> finanzielle Risiken
- Cyber-Attacken, Datenleaks, Diebstahl, Sicherheitsverletzungen
- Menschliches / organisatorisches Versagen (unberechtigte Zugriffe)
- Änderung von Gesetzen

## Vertragsarten

| Art            | Beschreibung                                        |
| -------------- | --------------------------------------------------- |
| AGB            | Vertragsbedingungen für eine Vielzahl an Verträgen  |
| Kaufvertrag    | Erwerb einer Sache / Rechts gegen Kaufpreis         |
| Werkvertrag    | Herstellung eines Werks (das Werk ist das Ergebnis) |
| Dienstvertrag  | Dienstleistung gegen Zahlung (nach Stunden)         |
| Mietvertrag    | zeitweise Gebrauchsüberlassung                      |
| Leasingvertrag | Nutzungsüberlassungsvertrag                         |

## SaaS-Vertrag

- Erwerben des Rechts auf befristete Nutzung einer Software

### wichtige Punkte im SaaS-Vertrag

- Vertragsart (i.d.R Miete)
- Vertragsparteien
- Datenspeicherung, -sicherung, -sicherheit
- Vertragsgegenstand (Art und Umfang der Leistungen)
- zusätzliche Leistungen (z.B. Schulungen)
- Vergütung, Zahlungsbedingungen
- Nutzungsrechte
- Gewährleistung und Haftung
- Leistungsgüte (SLA)
- Laufzeit, Kündigung, Herausgabe und Löschung von Daten
- Verarbeitung personenbezogener Daten
- Wartungszeiten, Störungsmanagement
- Schlussbestimmungen

### betroffene Vertragsarten bei SaaS

| Leistung                                  | Recht             |
| ----------------------------------------- | ----------------- |
| Nutzung von Saas                          | Mietrecht         |
| Aktualisierung der Software, Updates      | Werkvertragsrecht |
| Customizing (z.B. Anpassung der Software) | Werkvertragsrecht |
| Überlassung von IT-Speicherplatz          | Mietrecht         |
