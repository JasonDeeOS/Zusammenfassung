## Beispiele für steigende Risiken

- Umsetzung gesetzlicher Anforderungen -> finanzielle Risiken
- Cyber-Attacken, Datenleaks, Diebstahl, Sicherheitsverletzungen
- Menschliches / organisatorisches Versagen (unberechtigte Zugriffe)
- Änderung von Gesetzen

## Vertragsarten

| Art            | Beschreibung                                                                             |
| -------------- | ---------------------------------------------------------------------------------------- |
| AGB            | Vertragsbedingungen für eine Vielzahl an Verträgen                                       |
| Kaufvertrag    | Erwerb einer Sache / Rechts gegen Kaufpreis                                              |
| Werkvertrag    | Herstellung eines Werks (das Werk ist das Ergebnis)                                      |
| Dienstvertrag  | Dienstleistung gegen Zahlung (nach Stunden)                                              |

| Leihvertrag    | kein Entgelt im Zusammenhang mit der Verleihung                                          |

## SaaS-Vertrag

- Erwerben des Rechts auf befristete Nutzung einer Software

### wichtige Punkte im SaaS-Vertrag

- Vertragsart (i.d.R Miete)
- Vertragsparteien
- Datenspeicherung, -sicherung, -sicherheit
- Vertragsgegenstand (Art und Umfang der Leistungen)
- zusätzliche Leistungen (z.B. Schulungen)
- Vergütung, Zahlungsbedingungen
- Nutzungsrechte
- Gewährleistung und Haftung
- Leistungsgüte (SLA)
- Laufzeit, Kündigung, Herausgabe und Löschung von Daten
- Verarbeitung personenbezogener Daten
- Wartungszeiten, Störungsmanagement
- Schlussbestimmungen

### betroffene Vertragsarten bei SaaS

| Leistung                                  | Recht             |
| ----------------------------------------- | ----------------- |
| Nutzung von Saas                          | Mietrecht         |
| Aktualisierung der Software, Updates      | Werkvertragsrecht |
| Customizing (z.B. Anpassung der Software) | Werkvertragsrecht |
| Überlassung von IT-Speicherplatz          | Mietrecht         |

## Service-Level-Agreement

### Zweck

- transparente Gestaltung der Kontrolle/Beurteilung von Dienstleistungen für beide Vertragsparteien

### Vorteile von SLAs

- für beide:
	- Rechtssicherheit
	- genaue Definition von Anforderungen und Verantwortlichkeiten
	- Senkung der Koordinationskosten
	- Grundlage für Leistungsverrechnungen
- für DL:
	- leichtere Aufwandsabschätzung/leichtere Kalkulation
- für Kunden:
	- leichtere Überwachung des Leistungserbringers
	- Entscheidungsgrundlage

### Zu welcher ITIL-Phase gehören SLAs

- Service-Design-Phase -> SLA anhand Kundenanforderungen

### Wie kann die Erstellung von SLAs erleichtert werden?

- Verhindern von doppelten Inhalten & häufigen Änderungen
- Regelungen auf Unternehmens-, Kunden- und Service-Ebene

### Wichtige Inhalte eines SLAs

- Name von Dienstleister/Dienstnehmer/Ansprechpartner/Verantwortliche
- Genaue Beschreibung der zu erbringenden Leistungen
- Service-Level-Anforderungen und Ziele
- Eskalationsmanagement = Vorgehen bei Leistungsstörungen
- Antwort und Reaktionszeiten
- Laufzeit bzw. Kündigungsfristen
- Preismodell
