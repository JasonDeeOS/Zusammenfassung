- Daten werden gekapselt
- nur zugelassene Funktionen, Objekte oder Programme dürfen auf Attribute oder Methoden zugreifen
- Sichtbarkeiten legen fest was nach außen zugänglich ist

| Sichtbarkeit            | Beschreibung                                                                                                                                                                                                                                                                                                      |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| + public (öffentlich)   | Jeder darf auf die so gekennzeichneten Attribute und Funktionen zugreifen. Im obigen Beispiel heißt das, dass der Name des Raumschiffs von jedem gesetzt werden darf.                                                                                                                                             |
| - private (privat)      | Auf diese Attribute und Methoden darf nur von der Klasse selbst zugegriffen werden. Das Attribut Name kann also nur über die Methode setName() der eigenen Klasse gesetzt werden, oder auf irgendeine andere Art innerhalb der Klasse (z.B. innerhalb des Konstruktors, wenn ein Objekt der Klasse erstellt wird) |
| # protected (geschützt) | Elemente, die der gleichen Klasse angehören, oder die von dieser abgeleitet (vererbt) sind, dürfen zugreifen.                                                                                                                                                                                                     |
