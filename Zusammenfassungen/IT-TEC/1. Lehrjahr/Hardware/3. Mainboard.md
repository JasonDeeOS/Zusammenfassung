- zentrale Platine eines Computers
- Steckplätze
	- CPU
	- BIOS-Chip
	- RAM
- Anschlüsse für Peripherie / Erweiterungskarten

## verschiedene Größen eines Mainboards

- steigende Größe = mehr Möglichkeiten / Flexibilität / Leistungsfähigkeit
- Mini-ITX (vorwiegend mobile Geräte)
- Micro ATX (geringfügig größer, mehr Anschlüsse)
- ATX (gängigste, weil flexibelste Variante)
- XL-ATX (Gaming)
- E-ATX (Königsklasse)

## Mainboard-Anschlüsse

### CPU-Sockel für Prozessor

- mittig auf Platine
- fixiert mit Bügel
- nicht jede CPU mit jedem Mainboard kompatibel
- Intel und AMD-Sockel unterscheiden sich

### Stromversorgung (ATX Power Supply)

- 24-poliger Anschluss
- 8-poliger Anschluss für CPU

### Lüfter-Anschlüsse

- 4- und 3-polige Anschlüsse

### Onboard-GPU

- ausreichend für Office-Anwendungen

### RAM-Slots

- Random Access Memory
- unterschiedliche Varianten (DDR)
- Double Data Rate
- auf gleiche Kapazität / Taktung achten bei Erweiterung

### USB-Verbindungen

- blauer Stecker = USB 3.0

### PCI- / PCIe-Steckplätze

- je mehr von Steckplätzen (lanes) genutzt desto höher die Übertragungsrate
- Steckplätze x4, x8, x1
- lange Slots für Grafikkarte
- kurze Slots für Sound- / Netzwerkkarten

### SATA-Anschlüsse

- Serial-ATA
- Anschluss für Festplatten / SSDs
- Übertragungsstandard zwischen Laufwerken / Prozessor
- SATA III Anschlüsse sind blau
- zweifarbige Anschlüsse -> RAID möglich
	- Schreiben von Daten auf mehrere Festplatten
- SATA ist abwärtskompatibel

### Externe Anschlüsse / Schnittstellen für Peripherie

#### BIOS-Chip

- Basic Input-Output-System
- auf Mainboard integriert
- initialisiert / konfiguriert Hardware
- eigene Batterie -> Speicher bleibt intakt
- Initiieren des Betriebssystems

#### Chipsatz

- besteht traditionell aus 2 Chips
- regelt die Ansteuerung von Komponenten / Peripherie
- regelt Datenübertragung zwischen CPU / RAM / GPU
