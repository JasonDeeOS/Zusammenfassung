## Einheitsvorsätze:

1 Byte = 8 Bit
### für Datenmengen

| Abk. | Name | Faktor |
| ---- | ---- | ------ |
| KiB  | Kibi | 2^10   |
| MiB  | Mibi | 2^20   |
| GiB  | Gibi | 2^30   |
| TiB  | Tibi | 2^40   |
### für Datenübertragung

| Abk. | Name | Faktor |
| ---- | ---- | ------ |
| kB   | Kilo | 10^3   |
| MB   | Mega | 10^6   |
| GB   | Giga | 10^9   |
| TB   | Tera | 10^12  |

  
`Bsp: 475 GiB → GB`

`(475 GiB * 2^30) / 10^9 = 510,03 GB`

`Bsp: 256 GB → GiB`

`(256 GB * 10^9) / 2^30 = 238,42 GiB`

`Formel: (Zahl * Eigenfaktor) / Zielfremdfaktor`
