## x86

- Intel / AMD hat Lizenz erworben
- CISC (Complex Instruction Set Computing)
	- großer / komplexer Satz an Maschinenbefehlen
- Vorteile
	- Leistungsstark für große / komplexe Aufgabe
- Nachteile
	- höherer Energieverbrauch
	- langsamere / komplexere Steuerung
- Einsatzgebiete
	- Desktop PCs
	- Laptops
	- Server

## ARM

- ARM (Advanced RISC Machine)
- RISC (Reduced Instruction Set Computing)
- kleinerer Satz von einfachen und schnellen Befehlen
- Vorteile
	- schneller in Ausführung
	- geringerer Stromverbrauch
- Nachteile
	- mehr Befehle für komplexere Aufgaben
- Einsatzgebiete
	- mobile Geräte
	- Smartwatch
	- Router
	- Raspberry Pi

## Fazit

- Akkulaufzeit & Mobilität
	- ARM
- Hohe Leistung & hohe Komplexität
	- x86
