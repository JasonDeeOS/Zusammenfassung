- ruft Befehle eines Programms auf, prüft diese und führt sie aus

## Aufbau der CPU (Beispiel)

### GPU

- optional

### 1. Kern

- Rechenwerk
- Steuerwerk
- Register
- Cache L1 und L2
- verbunden mit Bus

### 2. Kern

- Rechenwerk
- Steuerwerk
- Register
- Cache L1 und L2
- verbunden mit Bus

### Bus-System

- verbindet Kerne, Speichermanager, L3 Cache (und GPU)
### Speichermanager

- mit Zugriff auf Daten im Arbeitsspeicher
- verbunden mit Bus

### Cache L3

- verbunden mit Bus

## Steuerwerk

- steuert Befehlsverarbeitung; Befehlsdecoder
	- Übersetzung der Maschinenbefehle, die vom Prozessor interpretiert werden können (laden, dekodieren, interpretieren)

## Rechenwerk

- verarbeitet Befehle vom Steuerwerk
- Hauptbestandteil: ALU (Arithmetic Logic Unit)

## Register

- kleiner schneller Speicher in der Nähe des Rechenwerks
- Befehlsregister erhält aktuellen Maschinenbefehl
- Befehlszähler erhält Adresse des nächsten Befehls
- Status / Flagregister erhält Status der aktuellen Operation

## Cache

- schneller Zwischenspeicher für Daten aus RAM
- Typen: 
	- L1 & L2 (pro Kern - L1 am schnellsten
	- L3 (gemeinsam alle Kerne) - L3 am größten

## Mehrkernprozessoren

- Single-Core, Dual-Core, Quad-Core, Hexa-Core, Octa-Core

## Befehlsabarbeitung

1. Befehl laden -> Befehlsregister
2. Befehlszähler erhöhen und Befehl dekodieren
3. benötigte Wert aus Arbeitsspeicher oder Register laden
4. ALU (Rechenwerk) führt Operation aus
5. Ergebnis wird ausgegeben -> Statusregister

## CPU-Technik

| Faktor           | Erklärung                                                                                                                                                                                                                      |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Frequenz         | Taktfrequenz bestimmt Ausführungsgeschwindigkeit bzw. Befehle, die pro Zeiteinheit ausgeführt werden können<br><br>Pro: <br>Je höher, desto mehr Berechnungen pro Sekunde<br>Contra: <br>höhere Wärmeentwicklung               |
| Cache            | Pro:<br>geringere Zugriffszeit auf häufig verwendete Daten -> RAM Entlastung<br>Contra:<br>Flächenverbrauch auf der CPU steigt<br>höhere Kosten bei Fertigung im Vergleich zu RAM<br>nicht durch jede Software optimal genutzt |
| Anzahl der Kerne | mehrere Prozesse können gleichzeitig durchgeführt werden<br><br>Pro:<br>mehr Kerne = mehr Prozesse = schneller<br>Contra:<br>Fertigung (Kosten)<br>Wärme<br>Softwareunterstützung<br>Flächenverbrauch                          |
| Busbreite        | Anzahl der gleichzeitig übertragenen Bits<br><br>Pro:<br>größer = mehr Daten<br>Contra<br>Wärme<br>Softwareunterstützung<br>Flächenverbrauch<br>Kosten                                                                         |
