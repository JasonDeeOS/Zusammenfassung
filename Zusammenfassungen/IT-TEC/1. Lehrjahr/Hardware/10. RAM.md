- Laden von Anwendungen
- Ausführen von Spielen
- Laden von Daten aus [[12. Sekundärspeicher|Sekundärspeicher]] in RAM
	- Zugriffszeit schneller auf RAM als Sekundärspeicher
	- RAM ist also ein Zwischenspeicher
- flüchtig; löschen der Daten sobald ohne Strom
	- schnellere lesen / beschreiben

## SRAM (statischer RAM)

- schneller beim Lesen der Daten als DRAM
- ideal als Cache-Speicher
- behält elektronische Ladung länger
	- kein Refresh; stromsparender
- braucht mehr Platz als DRAM
	- teurer

## DRAM (dynamischer RAM)

- langsamer als SRAM
- günstiger
- DRAM ist platzsparender
- regelmäßiger Refresh
	- längere Zugriffszeiten
	- besser für Hauptarbeitsspeicher
- arbeitet heutzutage synchron
	- Speicherzugriff / Datenübertragung zeitgleich
	- SDRAM (synchronous DRAM)

## Speichermodul

### Aufbau

- Speicherchip
- Kontaktleiste mit Pins
- Kerbe

### Bauformen zur Datenübertragung

- DIMM (Dual Inline Memory Module)
	- doppelreihig; Speicherchips auf beiden Seiten
	- 64-Bit-Bus
- SO-DIMM
	- kleiner
	- Laptops / Tablets
- SDR-SDRAM (Single Data Rate - SDRAM)
	- Übertragung von Daten mit jedem Takt (veraltet)
- DDR-SDRAM (Double-Data-Rate-SDRAM)
	- doppelte Übertragungsrate

## Technologie  
  
### Speicherkapazität  
  
- gelegentliches Verwenden des Computers (Surfen): ca. 4GB  
- Gaming / Multimedia / Entwickler: mind. 32 GB  
  
### Taktfrequenz / Datenübertragungsrate  
  
- DDR4: Generationsnummer  
- DDR4-5600: Taktzyklus / Datenübertragungsrate  
- RAM-Takt  
	- Anzahl Zyklen pro Sekunde  
	- MHz 
- Datenübertragungsrate  
	- Daten pro Sekunde an [[5. CPU - Der Prozessor|CPU]] und zurück 
	- MT/s (Megatransfers)    
- Datenübertragungsrate doppelt so hoch wie Taktfrequenz    
- Bandbreite  
	- Daten pro Sekunde über Bus gesendet  
	- abhängig von MT/s und Busbreite  
	- GB/s  
  
### Timings / Latenzen (Verzögerungen)  
  
- Timings messen die Latenz  
- kleinere Zahlen Indiz für schnellere Leistung 
- tCL: Reaktionszeit von RAM  
- tRCD: Lesezeit des Speichers  
- tRP: minimale Taktzyklusverzögerung  
- tRAS: Zeit zwischen den Zugriffen  
  
### Dual Channel  
  
- Dual-Kit  
	- zwei Module in Zusammenarbeit
