## Primärspeicher

- direkt von CPU angesprochen
- Register (flüchtig)
- Cache (flüchtig)
- RAM (flüchtig)
	- DRAM (Dynamic Random Access Memory)
	- SRAM (Static Random Access Memory)
	- VRAM (Video Random Access Memory)
- ROM (Read Only Memory) (nicht flüchtig)

## Sekundärspeicher

- nicht direkt von CPU angesprochen
- HDD Festplatte; auch extern (magnetisch)
- SSD; auch extern (flash)
- CD, DVD (optisch)
- Speicherkarten (flash)
- USB (flash)
- Magnetband (magnetisch)
- Diskette (magnetisch)

## Tertiärspeicher

- Cloudspeicher
