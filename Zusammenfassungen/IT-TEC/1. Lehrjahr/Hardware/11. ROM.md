## Read Only Memory
  
- nicht flüchtiger Speicher: speichert Daten auch bei Stromunterbrechung  
- Ändern / Löschen von Daten nicht möglich  
	- Festwertspeicher  
- Speicher von Programmen/Daten, welche dauerhaft und unverändert verfügbar sein müssen  
	- z. B. BIOS (Basic Input Output System)  
- mittlerweile gibt es auch programmierbare ROM

### nur lesbar

| MROM | masked read only memory |
| ---- | ----------------------- |
### programmierbar

| PROM         | programmable read only memory                           | vom Anwender nur 1 mal programmierbar<br><br>Anwendung: Bei Geräten, die keine Firmware-Updates benötigen z.B. Sensoren / Maschinensteuerungen |
| ------------ | ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| EPROM        | erasable programmable read only memory                  | kann gelöscht werden und neu programmiert werden -> mit UV-Licht                                                                               |
| EEPROM       | electrical erasable programmable ready only memory      | elektronisch löschbar<br>neu programmierbar<br>byteweise rel. langsam                                                                          |
| Flash-EEPROM | flash-electrical erasable programmable read only memory | Weiterentwicklung EEPROM<br>elektronisch löschbar<br>blockweise schneller & größere Datenmenge                                                 |
