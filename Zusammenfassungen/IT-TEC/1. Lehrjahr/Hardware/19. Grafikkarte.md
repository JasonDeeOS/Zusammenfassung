## Aufgabe der GPU

- mathematische Berechnungen zur Darstellung der korrekten Pixel auf dem Bildschirm
## GPU-Arten

| Kriterium                 | Integrierte APU (Ein-Chip-System) | Dediziert (Steckplatz) | OnBoard           |
| ------------------------- | --------------------------------- | ---------------------- | ----------------- |
| Erklärung                 | GPU auf [[5. CPU - Der Prozessor|CPU]]-Chip eingebaut        | eigenständige GPU      | GPU auf [[3. Mainboard|Mainboard]] |
| Leistungsfähigkeit        | mittel                            | hoch                   | gering            |
| Grafikspeicher            | nein                              | ja                     | nein              |
| Umgang bei Defekt         | CPU defekt                        | GPU defekt             | GPU defekt        |
| Geeignete Einsatzbereiche | Handy                             | Gaming                 | Laptop            |

```
Welche Vor- bzw. Nachteile bietet eine APU-Grafikkarte im Vergleich zu einer Dedizierten?
```
### Vorteile

- kleiner
- günstiger
- stromsparend
### Nachteile

- geringere Leistung
- teilt sich [[10. RAM|RAM]] mit System
- eingeschränkte Upgrade Möglichkeiten
- Tauschbarkeit

- Berechnung
## Grafikspeicher (VRAM)

- Zwischenspeichern
## Spannungswandler / Spannungsversorgung

- Umwandlung und Stabilisierung der Spannung
## Stromquellen (inkl. Watt Angaben)

| Stromversorgung                | Max. Leistung in Watt |
| ------------------------------ | --------------------- |
| PCIe                           | 75 W                  |

| PCIe + 2× 6-Pin-Anschluss      | 225 W                 |
| PCIe + 6-Pin + 8-Pin-Anschluss | 300 W                 |
| PCIe + 8-Pin-Anschluss         | 225 W                 |

## Spannungsregler

- Grafikkarte besitzt eigene Spannungsregler (Voltage Regulator Modules, VRM), die die vom [[17. Netzteil|Netzteil]] und PCI-Slot ankommende Spannung auf die benötigten Werte herunterregeln und stabilisieren
## Leistungsmerkmale von Grafikkarten

- Taktfrequenz
- VRAM
- Kerne
- Speicher-Typ
- Raytracing
- Anschlüsse
- PCIe Generation
## Kühlung

- aktive Kühlung (Lüfter)
- passive Kühlung (Heatsink)
- Wasserkühlung
