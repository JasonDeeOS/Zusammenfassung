## pi@raspberry:~$

- "~" = home directory des Users
- "$" = als normaler Benutzer angemeldet
- "#" = root access
## Befehl pwd!

- Ergebnis /home/pi
- ACHTUNG: Linux ist case sensitive

## Befehl sudo -i

- Root-Shell starten
- root@raspberry:~#
- pwd! ergibt jetzt /root

## Manövrieren im Verzeichnisbaum

- Befehl: cd /etc
- change directory to etc
- relative Pfadangabe
	- zB cd ../../Foldername
	- ab aktuellen Verzeichnis
- absolute Pfadangabe
	- zB cd /etc/Foldername
	- kompletter Pfad ab Home
- ".." -> eine Verzeichnisebene zurück

## Befehl ls

- ls zeigt Ordner und Dateien im Verzeichnis an
- Zusatz "-la" zeigt mehr Details an

## spezielle Ordner

- /root -> Home-Verzeichnis des Root-Superusers
- /home -> Verzeichnis aller Nutzer; persönliche Daten
- /etc -> Systemkonfig
