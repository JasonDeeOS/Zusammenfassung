Was ist Node-Red?

- von IBM entwickelt
- OpenSource
- Verbindung von Hardware, Schnittstellen und Services
- grafische Programmierung
	- nodes werden zu flow verbunden

## Die Oberfläche von Node-RED

- Startbefehl: node-red-start
- Aufruf der Oberfläche durch `http://<ip-adresse>:1880

## inject-node

- Injektion einer Payload manuell oder in regelmäßigen Intervallen
- Datentypen
	- Zeitstempel
	- string
	- boolean
	- Zahlen
	- JS-Objekte

## rpi - gpio out - node

- erwartet 0 oder 1 im digitalen Modus
	- schaltet PIN auf LOW und HIGH
- Anfangswert kann gesetzt werden (PIN-Zustand initialisieren)

## PWM

- Pulsweitenmodulation
- Steuerung elektrische Leistung

## Grundprinzip

- nicht dimmen sondern takten
	- volle Spannung in kurzen Impulsen
- Pulsbreite entscheidet über Kraft
	- langer Puls (breit) = mehr Energie
	- kurzer Puls (lang) = weniger Energie
- Tastgrad = Verhältnis zu an und aus
