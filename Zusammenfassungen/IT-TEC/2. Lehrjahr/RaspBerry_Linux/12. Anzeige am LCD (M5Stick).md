## Unser erster Sketch

### Wichtig

``` C
setup() // Wird beim Start des Programms einmalig aufgerufen
```

``` C
loop() // wird nach dem Start in Endlosschleife durchlaufen, solange der M5Stick eingeschalten ist
```

### Sketch

``` C
#include <M5StickC.h>

void setup() {
	M5.begin();
	pinMode(M5_LED, OUTPUT)
}

void loop() {
	digitalWrite(M5_LED, HIGH);
	delay(1000);
	digitalWrite(M5_LED, LOW);
	delay(1000);
}
```

### Funktion

- rote LED am M5Stick leuchtet 1 Sekunde und ist 1 Sekunde aus in Dauerschleife
- wichtig ist die Bibliothek <M5StickC.h>

## Aufgabe 1 Zähler mit Tasten steuern

- M5Stick hat 2 programmierbare Taster (A & B) und einen Ausschalter

### Ausgabe

- Die Anzeige erfolgt über den seriellen Monitor zunächst
``` C
Serial.print(); // Ausgabe im Seriellen Monitor ohne Zeilenvorschub
Serial.println(); // Ausgabe im Seriellen Monitor mit Zeilenvorschub
M5.update(); // Befehl zum Auslesen von Veränderungen am M5Stick
M5.BtnA.wasPressed(); // prüft Zustand des Tasters im Vergleich zum letzten Lesevorgang
```

## Aufgabe 2 Zähler mit Tasten steuern und am LCD ausgeben

``` C
M5.Lcd.print(); // Ausgabe des Textes ohne Zeilenvorschub
M5.Lcd.println(); // Ausgabe des Textes mit Zeilenvorschub
M5.Lcd.setCursor(x,y,z); // Beginn der Schreibposition auf dem Display (x,y); z = Font
M5.Lcd.setTextColor(Farbe); // Textfarbe
M5.Lcd.fillScreen(Farbe); // Hintergrundfarbe
M5.Lcd.setTextSize(size); // Schriftgröße
```
