## neue Linux-Befehle

- `nano Taster-LED.py` - Erstellt die Datei, wenn sie noch nicht existiert, und öffnet sie im Editor
- ``mkdir Partylight`` - Erstellt Ordner
- ``mv Taster-LED.py Partylight`` - Verschiebt die Datei in Zielordner
- ``cat Taster-LED.py`` - Zeigt Dateiinhalt im Terminal
- ``cp Taster-LED.py Taster-Countdown-LED.py`` - kopiert eine Datei unter neuen Namen
## Python

### Bibliotheken

``` Python
import RPi.GPIO as GPIO 
import time
``` 
- Nutzung der Pins als GPIO
- Nutzung von time.sleep

### Setmode festlegen

``` Python
  GPIO.setmode(GPIO.BCM)
```
- BCM -> GPIO-Nummerierung
- BOARD -> PIN-Nummerierung

### Variablen

``` Python
LED_GRUEN = 27
LED_ROT = 17
LED_BLAU = 22
TASTER = 24
```
- BCM-Nummerierung wird hier verwendet

### Ein- und Ausgänge festlegen

``` Python
GPIO.setup(LED_GRUEN, GPIO.OUT)
GPIO.setup(LED_ROT, GPIO.OUT)
GPIO.setup(LED_BLAU, GPIO.OUT)
GPIO.setup(TASTER, GPIO.IN)
```

### Initialisierung der Zustandsvariable

``` Python
  Zustand = 0
```

### Funktion wird bei Signaldetektion ausgeführt

``` python
def Partylight_State(null):
	global Zustand
	if Zustand == 0 or Zustand == 1:
		Zustand += 1
		print("Zustand ist ", Zustand)
	elif Zustand == 2:
		Zustand = 0
		print("Zustand ist ", Zustand)
```

### Beim Drücken des Tasters (fallende Signalflanke) wird die Callback-Funktion ausgelöst

``` Python
GPIO.add_event_detect(TASTER,GPIO.FALLING,callback=Partylight_State,bouncetime=300)
```

### Bei Zustand 0 sollen alle LEDs aus sein

``` Python
	if Zustand == 0:
		GPIO.output(LED_ROT,GPIO.LOW)
		GPIO.output(LED_GRUEN,GPIO.LOW)
		GPIO.output(LED_BLAU,GPIO.LOW)
```
### Bei Zustand 1 sollen die LEDs nacheinander aufleuchten

``` Python
	elif Zustand == 1:
		GPIO.output(LED_ROT,GPIO.HIGH)
		time.sleep(1)
		GPIO.output(LED_ROT,GPIO.LOW)
		GPIO.output(LED_GRUEN,GPIO.HIGH)
		time.sleep(1)
		GPIO.output(LED_GRUEN,GPIO.LOW)
		GPIO.output(LED_BLAU,GPIO.HIGH)
		time.sleep(1)
		GPIO.output(LED_BLAU,GPIO.LOW)
```
### Bei Zustand 2 sollen alle LEDs gleichzeitig leuchten

``` Python
	elif Zustand == 2:
		GPIO.output(LED_ROT,GPIO.HIGH)
		GPIO.output(LED_GRUEN,GPIO.HIGH)
		GPIO.output(LED_BLAU,GPIO.HIGH)
```
