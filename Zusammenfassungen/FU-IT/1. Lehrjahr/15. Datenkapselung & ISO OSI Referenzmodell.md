- besteht aus 7 Schichten
- basiert auf DOD-Schichtenmodell
- OSI ist feiner / detaillierter
- Schichten beinhalten Aufgaben / Funktionen / Verfahren / Protokolle
	- stellen der übergeordneten Schicht Dienstleistungen
- Zwischenstationen wie [[10. Koppelelement Router|Router]] / [[8. Koppelelement Switch|Switch]]

## Kommunikationssysteme

### geschlossen

- herstellerabhängig
- firmenbezogene Protokolle
- individuell und firmenbezogen
	- Einbinden und Fremdsystemen nicht möglich

### offen

- Einhaltung gewisser Richtlinien
	- ermöglicht Kompatibilität mit Geräten / Schnittstellen
- Richtlinie; Referenzmodell für die Kommunikation offener System
	- OSI-Modell
- Grundlage für Design und Kommunikationssysteme

## Protokolle im OSI-Modell

- Protokoll = Sammlung von Regeln
- Übergänge zwischen Schichten = Schnittstellen
- Protokolle können über mehrere Schichten agieren und mehrere Aufgaben

## Einteilung

- 7 Schichten
- jede Schicht hat bestimmte Aufgabe
- Schichten können angepasst, zusammengefasst oder ausgetauscht werden
- 1 - 4 = transportierende Schichten
- 5 - 7 = anwendungsorientierte Schicht
- Übertragungsmedium nicht festgelegt

### Schicht 7 - Anwendungsschicht - application layer

- Dienste für Anwendersoftware / Anwender
- wichtiges Schicht für Anwender
- Anwendungen nicht Teil des OSI-Modells
- Dienste; Protokolle z.B.
	- FTP (File Transfer Protocol) zur Datenübertragung
	- TELNET (virtuelles Terminal)
	- HTTP (HyperText Transfer Protocol)

### Schicht 6 - Darstellungsschicht - presentation layer

- Vereinbaren von Datenformen / Datenkodierung
- Umwandlung zwischen verschiedenen Darstellungen
- Übertragung von Dateninhalt + Erhalt des Informationsgehalts
- Verwendung einer einheitlich genormten Kodierung
- ermöglicht Datenaustausch zwischen unterschiedlichen Systemen

### Schicht 5 - Steuerungsschicht - session layer

- Auf- / Abbau von Kommunikationsbeziehungen (Sitzung / Session)
- Wiederherstellung der session bei Störungen

### Schicht 4 - Transportschicht - transport layer

- Aufgabe: Senden von Daten fehlerfrei, vollständig, in der richtigen Reihenfolge
- oberste Schicht des Transportsystems
- kümmert sich um Probleme der Vermittlungsschicht
- Segmentierung von Datenpaketen
	- Übertragen beliebig langer Nachrichten
	- Unterteilen in Segmente
	- Zusammensetzung beim Empfänger

### Schicht 3 - Vermittlungsschicht - network layer

- Adressierung des Zielsystems
- Wegesuche durch Zwischensysteme
- Verbindung von Endsystemen und [[17. Routing|Routing]]

### Schicht 2 - Sicherungsschicht - data link layer

- Verbindung von Teilstrecken
- Übertragung fehlerfreier Bitströme bei gelegentlicher Störung
- überträgt Frames
- Frames müssen fehlerfrei übertragen werden
- Bereitstellen von Fehlererkennung / -beseitigung
- Fehlersicherung
	- Fehlererkennung durch Paritätsbits / Prüfsummen / Code
	- Fehlerkorrektur durch Code / erneutes Anfordern
- Rahmensynchronisation
	- Erkennen von Anfang / Ende des Frames
		- durch Frame-Synchronisation
	- Zuordnung und korrekte Interpretation durch Bilden von Frames
- Flusssteuerung
	- Berücksichtigung der Empfangsbereitschaft des Empfängers
		- Verhinderung der Überschwemmung mit Frames
	- Verhindern der Überschwemmung bei schnelleren Sendern
	- große Pufferspeicher; vorteilhaft aber teuer
	- Mechanismus der einen schnellen Sender zum Warten veranlasst

### Schicht 1 - Bitübertragungsschicht - physical layer

- Übertragung einzelner Bits
- Definiert physikalische / technische Eigenschaften der Übertragungsmedien
- Mechanisch; Schnittstelle zwischen Station und Übertragungsmedium
- Elektrisch; definiert die Kodierung der Bits
- Prozedural; Abläufe, die für die Bitübertragung erforderlich sind
