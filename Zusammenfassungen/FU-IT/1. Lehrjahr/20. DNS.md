## Hostname

- ist innerhalb der Subdomain eindeutig
- hierarchische Struktur
	- erlaubt eindeutige weltweite Zuordnung

## Subdomain

- Untergruppierung einer größeren Gruppierung (z.B. Unternehmen)
- optional und durch Domain verwaltet

## Second-Level-Domain / Sublevel Domain

- Schnittstelle zwischen Unternehmen und WWW
- dienen meist der logischen Gliederung einer Domain

## Top-Level-Domain

- nationale Organisation oder Art eines Unternehmens (z.B. .de, .org)

## Root

-  Punkt am Ende eines jeden DNS-Namens
- die meisten Anwendungen ergänzen diesen selbstständig

## FQDN

- Fully Qualified Domain Name
- weltweit eindeutige Kombination aus Gerätenamen, Subdomain und Top-Level-Domain

## DNS-Server

- FQDNs werden von Servern verwaltet
- aus Effizienzgründen haben diese Kopien von Datenbanken anderer Server

## Rekursive und iterative Namensauflösung

- rekursiv; DNS-Server fragt andere bis er IP hat
- iterativ; Client fragt mehrere DNS-Server an bis IP gefunden
