## öffentliche IP

- direkter Zugriff über Internet
- vom ISP zugewiesen
- Vergleich mit einem Postfach
- öffentlich / extern wird synonym gebraucht
- kann zurückverfolgt werden durch ungefähren Standort über ISP
	- Websites nutzen außerdem IP-Tracking
	- Verhindern durch VPN oder Proxy

## private IP

- Zuweisung durch Netzwerkrouter über DHCP
- eindeutige IP in einem Netzwerk
- ermöglicht Kommunikation im selben Netzwerk ohne Internet
- fördern Sicherheit
- Leitung des Internetverkehrs durch Router
- private / lokale wird synonym gebraucht
- kann zurückverfolgt werden; nur von Geräten im lokalen Netzwerk
	- online nicht sichtbar

## Unterschied öffentlich <-> privat

- Reichweite
	- öffentlich; Internet
	- privat; lokales Netzwerk

## Bereich öffentlicher / privater IP-Adressen

- Reservierung privater IP durch IANA (Internet Assigned Numbers Authority)
- Wiederverwendung in verschiedenen privaten Netzwerken
- alle andere Adressen sind öffentlich und demnach einzigartig

| Klasse A | 10.0.0.0 - 10.255.255.255     |
| -------- | ----------------------------- |
| Klasse B | 172.16.0.0 - 172.31.255.255   |
| Klasse C | 192.168.0.0 - 192.168.255.255 |
## ARP (Address Resolution Protocol)

- Ermittlung der MAC-Adresse zu einer bekannten IP-Adresse
- Einträge erfolgen statisch oder dynamisch
- Aufbau eines ARP-Pakets (= Datenfeld eines Ethernet-Frames)

| 7 Bytes  | 1 Byte | 6 Bytes      | 6 Bytes       | 2 Bytes        | ==46 - 1500 Bytes== | 4 Bytes |
| -------- | ------ | ------------ | ------------- | -------------- | --------------- | ------- |
| Präambel | SFD    | Zieladressen | Quelladressen | Typ oder Länge | ==Daten==           | FCS     |


| Hardwareadresstyp (2 Bytes)   | Typ der MAC-Adresse im Paket                                                                                              |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Protokolladresstyp (2 Bytes)  | Protokolltyp für den die MAC-Adresse angefordert wird                                                                     |
| Hardwareadressgröße (1 Byte)  | Größe der MAC-Adresse                                                                                                     |
| Protokolladressgröße (1 Byte) | Größe des Protokolls                                                                                                      |
| Operation (2 Byte)            | Wer der Operation, die ausgeführt werden soll; 1 = ARP-Request, 2 = ARP-Reply                                             |
| Quell-MAC-Adresse (6 Bytes)   | enthält bei ARP-Request die MAC-Adresse des Senders. enthält bei ARP-Reply die MAC-Adresse des antwortenden Hosts         |
| Quell-IP-Adresse (4 Bytes)    | enthält bei ARP-Request die IP-Adresse des anfragenden Hosts. enthält bei ARP-Reply die IP-Adresse des antwortenden Hosts |
| Ziel-MAC-Adresse (6 Bytes)    | bei ARP-Request undefined. bei ARP-Reply enthält die MAC-Adresse des anfragenden Hosts                                    |
| Ziel-IP-Adresse (4 Bytes)     | bei ARP-Request enthält IP-Adresse des gesuchten Host. bei ARP-Reply enthält es die IP-Adresse des anfragenden Hosts      |
