- jeder Host soll in einem dezentralen TCP/IP-[[1. Netzwerk|Netzwerk]] gefunden werden
- Zuteilung logischer [[9. IPv4|IPv4]] Adressen zu jedem Hardware-Interface
- Adressraum umfasst 32 Bit
	- von 0.0.0.0 bis 255.255.255.255 (2<sup>32</sup>)
- 5 Klassen wurden festgelegt (A, B, C, D)

Einteilung der Adressklassen

| Klasse A | 0.0.0.0 - 127.255.255.255   |
| -------- | --------------------------- |
| Klasse B | 128.0.0.0 - 191.255.255.255 |
| Klasse C | 192.0.0.0 - 223.255.255.255 |
| Klasse D | 224.0.0.0 - 239.255.255.255 |
| Klasse E | 240.0.0.0 - 255.255.255.255 |
