- gesendete Daten aufgeteilt in Blöcke (Frames)
- festgelegte Struktur

| Header   | Header | Header      | Header            | Header  |                | Trailer |
| -------- | ------ | ----------- | ----------------- | ------- | -------------- | ------- |
| 7 Bytes  | 1 Byte | 6 Bytes     | 6 Bytes           | 2 Bytes | 46-1500  Bytes | 4 Bytes |
| Präambel | SFD    | Zieladresse | Quell-[[3. MAC-Adresse|MAC-Adresse]] | Typ     | Daten          | FCS     |
Framegröße: 64 bis 1516 Bytes (ohne Präambel und SFD)

| Präambel                    | Dient der Synchronisation                                                                                            |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| SFD (Start Frame Delimiter) | Bitmuster (10101011) zur Anzeige des eigentlichen Framebeginns                                                       |
| Zieladresse                 | MAC-Adresse des Empfängers                                                                                           |
| Quell-MAC-Adresse           | MAC-Adresse des Senders                                                                                              |
| Typ                         | Auskunft über Protokoll der höheren [[15. Datenkapselung & ISO OSI Referenzmodell|OSI]]-Schicht                                                                      |
| Daten                       | Nutzdaten                                                                                                            |
| PAD                         | wird nur benötigt, wenn die Minimalgröße von 64 Bytes nicht erreicht wird. In diesem Fall wird mit Nullen aufgefüllt |
| FCS (Frame Check Sequence)  | Prüfsumme, dient der Fehlererkennung                                                                                 |
