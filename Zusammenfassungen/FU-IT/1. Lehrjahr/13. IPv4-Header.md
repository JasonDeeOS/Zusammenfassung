## Version

- IP-Protokollversion
	- [[9. IPv4|IPv4]]
	- [[1. IPv6|IPv6]]

## Headerlänge / Internet Header Length (4 Bit)

- mind. 5 x 32 Bit (20 Byte)
- max 15 x 32 Bit (60 Byte)

## Diensttyp / Type of Service (8 Bit)

- maximale Größe des Pakets in Bytes
- max 65535 Byte / 64 kB
- gängige Mindestlänge ist 1500 Bytes

## Identifikation (16 Bit)

- alle Fragmente weisen dieselbe Identifikationsnummer auf
	- sicherstellen der korrekten Zusammensetzung für höher Schichten

## Flags (3 Bit)

- Angabe möglicher Aufteilung der Pakete
- DF = 0 (May Fragment); DF = 1 (Don't Fragment)
- MF = 0 (More Fragment) heißt letztes Fragment, MF = 1 heißt es kommen mehr

## Fragmentabstand (13 Bit)

- korrekte Herstellung der Ursprungsequenz
- erstes Fragment = 0

## Time To Live (8 Bit)

- maximale Lebensdauer
- in der Praxis nicht als Zeitbegrenzung genutzt
- Größe wird von jeden Knoten reduziert
- bei längerem Zwischenspeichern wird der Wert mehrmals verringert

## Protokoll (8 Bit)

- Nummer des SAP (Service Access Points)
- Definiert welches Protokoll die Weiterverarbeitung übernimmt

## Header-Prüfsumme (16 Bit)

- Prüfsumme für den gesamten IP-Header
- muss bei jedem verarbeitenden System neu berechnet werden

## Quelladresse, Zieladresse (je 32 Bit)

- Absender + Empfänger IP

## Optionen

- optionale Informationen
	- Routen-Ermittlung
	- erweiterte Fehlerbehebung

## Füllbits

- Paket muss aus kompletten 32 Bit Worten bestehen
- fehlende Bits mit 0 auffüllen

## Daten

- Nutzdaten der höheren Schicht
