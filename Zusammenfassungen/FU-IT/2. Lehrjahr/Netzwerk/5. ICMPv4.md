- Internet Control Message Protocol
- Austausch von Fehler und Kontrollmeldungen
- Vermittlungsschicht
- Protokollnummer 1
- bei IPv6 durch ICMPv6 ersetzt

## Aufbau des Headers

- keine eigene Struktur
	- Standard IP Header wird genutzt
- einige Felder werden bei ICMPv4 angepasst
	- Typ-of-Service auf 0000
	- IP-Header-Feld auf 0001
	- Datenbereich wird ICMP-Bereich (ICMP-Typ, ICMP-Code, ICMP-Check-Summe, ICMP-Daten-Bereich)
- ICMP-Datenbereich enthält 64 Bit IP-Daten des IP-Pakets
