## Source Port (16 Bit)

- Quellport
## Destination Port (16 Bit)

- Zielport
## Sequence Number (32 Bit)

- Erhalt der richtigen Reihenfolge
- Initial Sequence Number (ISN) wird zufällig gewählt
## Acknowledgement Number (32 Bit)

- Angabe, welche Sequenznummer das empfangende System zur Bestätigung verwenden soll
## Offset / Header Length (4 Bit)

- Länge des Headers in 32-Bit-Wörter
## Reserve

- reserviert für zukünftige Anwendungen
## Flags (12 Bit)

- im Moment 8 Bits = 8 Flags
- Rest ist reserviert für weitere
## Fenstergröße

- Anzahl der Bits, die ein Gerät maximal empfangen kann
## Prüfsumme

- Kontrolle der Daten auf Veränderung
## Dringlichkeitszeiger

- URGENT-Flag
- kein laden in den Puffer
- direkte Bearbeitung
## Optionen

- Maximalgröße der TCP-Segmente definiert und Rest wird mit Nullen aufgefüllt
