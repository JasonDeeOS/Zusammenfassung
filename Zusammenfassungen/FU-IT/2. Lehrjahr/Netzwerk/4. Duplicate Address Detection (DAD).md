- SLAAC ist ein stateless Prozess
	- stellet sicher, dass die IPv6 Global Unicast einzigartig ist
- DAD wird durch ICMPv6 genutzt

## Ablauf

1. Host sendet ICMPv6 Neighbour Solicitation (NS)
	   benutzt spezielle IPv6 Solicited-Node Multicast Address
2. keine Antwort mit Neighbour Advertisement (NA) bedeutet, dass die Adresse einzigartig ist
   wenn ein NA zurück kommt muss eine neue Interface ID gewählt werden
