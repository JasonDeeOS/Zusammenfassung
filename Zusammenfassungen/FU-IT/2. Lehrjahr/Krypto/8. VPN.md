- Virtual Private Network

## Anforderungen

- Authentizität
	- identifiziert zweifelsfrei Kommunikationspartner
- Integrität
	- Garantie für unveränderte Daten während der Übertragung
- Vertraulichkeit
	- nur autorisierte Empfänger

## Anwendungsbereiche

### Site-to-Site

- 2 VPN-Gateways erforderlich, die direkt miteinander kommunizieren
- z.B. Anbindung einer Zweigstelle an den HQ-Standort eines Unternehmens
### End-to-End

- Verbindung zwischen zwei Endgeräten
- kein Gateway erforderlich
- Client- und Serverstoftware auf den Endgeräten
### End-to-Site

- Verbindung eines externen Clients mit Unternehmensnetz
- 1 VPN-Gateway erforderlich

| Art          | Vorteile                                                                                                                               | Nachteile                                                                                                                         |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Site-to-Site | Skalierbarkeit (Standortanzahl / Netzwerkgröße), User-Experience eines einzigen Netzwerks                                              | Gateways erforderlich (Kosten), Konfiguration / Administration erforderlich, keine Ende-zu-Ende-Verschlüsselung                   |
| End-to-End   | sicherer, verschlüsselter Fernzugriff auf Hosts möglich, unabhängig von Netzwerkarchitektur des Betreibers, keine zus. HW erforderlich | spezielle VPN-SW auf den Endgeräten erforderlich, u.U. Konfiguration von Zwischenstationen nötig, Kompatibilitätsprobleme möglich |
| End-to-Site  | sicherer, verschlüsselter Fernzugriff auf Netzwerk möglich, flexibel in der Nutzung, skalierbar, kosteneffizienter als Site-to-Site    | Gateway erforderlich, hoher Administrationsaufwand, Performance abhängig von Internet-Infrastruktur                               |
