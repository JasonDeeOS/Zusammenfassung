- Schicht 3 
- schützt IP-Pakete
- Typischer Einsatz: VPN-Tunnel
## Ziel:

- Daten verschlüsseln
- Kommunikationspartner authentifizieren (z.B. bei VPN)
- Manipulation erkennen
- Datenintegrität sicherstellen
## Protokolle
### Authentication Header

- Sorgt für:
    - Authentifizierung
    - Integrität
- Verschlüsselt die Daten **nicht**
- Schützt vor Manipulation
- Wird heute eher selten verwendet
### Encapsulation Security Payload

- Wichtigster Bestandteil von IPsec
- Sorgt für:
    - Verschlüsselung
    - Authentifizierung
    - Integrität
- Wird in der Praxis deutlich häufiger genutzt als AH

### Merksatz:

> **ESP schützt den Inhalt, AH prüft hauptsächlich die Echtheit.**

### Transport Mode

- Nur die Nutzdaten werden geschützt
- Der ursprüngliche IP-Header bleibt erhalten
- Wird eher bei direkter Kommunikation zwischen zwei Endgeräten verwendet

```
IP-Header | verschlüsselte Nutzdaten
```

Vorteil:

- Weniger Overhead

Nachteil:

- Quell- und Ziel-IP bleiben sichtbar

### Tunnel Mode

- Das komplette ursprüngliche IP-Paket wird geschützt
- Ein neuer IP-Header wird außen hinzugefügt
- Typisch für VPNs

```
neuer IP-Header | verschlüsseltes ursprüngliches IP-Paket
```

Vorteil:

- Sehr gut für VPN-Verbindungen geeignet
- Interne IP-Adressen werden verborgen

Nachteil:

- Mehr Overhead
