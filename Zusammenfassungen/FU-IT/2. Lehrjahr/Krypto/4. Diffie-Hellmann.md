- ermöglicht den Austausch eines geheimen Schlüssels über einen unsicheren Kanal

## Verfahren

- einigen auf eine große Primzahl n und eine ganze Zahl g
	- n und g sind öffentlich
- A erzeugt Zufallszahl x und sendet X = g<sup>x</sup> mod n an B
	- X ist öffentlich, x ist privat
- B erzeugt Zufallszahl y und sendet Y = g<sup>y</sup> mod n an A
	- Y ist öffentlich, y ist privat
- beide berechnen abschließend key = X<sup>y</sup> mod n = Y<sup>x</sup> mod n
